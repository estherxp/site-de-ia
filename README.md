📚 Mente Digital - README
🧠 Sobre o Projeto (criado para estudos) 
Mente Digital é um site completo de e-commerce para venda de assistentes de inteligência artificial futuristas. O projeto simula uma experiência real de compra, com design moderno, carrinho funcional, checkout simulado e um chat interativo com IA contextualizada.

✨ Funcionalidades Principais
1. 🛒 Loja de Assistentes IA

5 produtos disponíveis:
NOVA MIND - Produtividade e estudos (R$299)
ORION PRO - Empresarial e automação (R$599)
LYRA ART - Criatividade e conteúdo (R$399)
VEGA LAB - Pesquisa científica (R$499)
ATLAS MAX - Estratégia e decisões (R$799)

3. 📅 Planos Mensais
ESSENTIAL - R$49/mês (1 assistente)
PRO - R$99/mês (3 assistentes)
ULTRA - R$199/mês (todos assistentes + benefícios)

3. 🛍️ Carrinho de Compras
Adicionar/remover produtos
Alterar quantidades
Cálculo automático do total
Persistência com LocalStorage
Painel lateral deslizante

4. 💳 Checkout Simulado
Formulário completo (nome, email, telefone, endereço)
Múltiplos métodos de pagamento (Cartão, PIX, Cripto)
Validação de campos obrigatórios
Geração de número de pedido fictício
Modal de confirmação

5. 🤖 Chat IA Inteligente
Respostas contextuais sobre os produtos
Reconhece perguntas sobre:
"Melhor para estudos"
"Qual comprar"
"Diferença entre assistentes"
Preços e planos
Cada assistente específico
Indicador de digitação
Limpeza do chat

6. 🎨 Design Interativo
Fundo que segue o mouse com partículas
Efeito de glow no cursor
Gradientes neon (ciano, roxo, magenta)
Glassmorphism (vidro fosco)
Animações suaves e hover effects
Grid futurista animado
Totalmente responsivo

🛠️ Tecnologias Utilizadas
Tecnologia	Aplicação
HTML5	Estrutura semântica do site
CSS3	Estilização, animações, glassmorphism, responsividade
JavaScript Puro	Toda a lógica de interatividade, carrinho, chat e checkout
LocalStorage	Persistência do carrinho entre sessões
Sem frameworks, sem dependências externas! 🚀
